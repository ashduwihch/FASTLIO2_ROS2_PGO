FASTLIO2 ROS 2 PGO 仿真适配版修改说明

项目来源：
https://github.com/liangheming/FASTLIO2_ROS2

本版本主要针对 Ubuntu 22.04、ROS 2 Humble、Gazebo Harmonic 和仿真 MID-360
数据链路进行了以下修改。

一、修正 IMU 加速度单位

ROS 2 的 sensor_msgs/msg/Imu 已使用 m/s² 表示线加速度。原代码在接收数据后
又乘以 10.0，会导致重力和运动加速度被放大十倍。当前版本删除了这次额外缩放，
避免姿态估计、坐标轴和点云出现异常漂移。

修改文件：fastlio2/src/lio_node.cpp

二、增加空点云保护

Gazebo 启动、暂停、场景切换或当前扫描没有有效命中时，可能发布 point_num 为 0
的空点云。原程序将空点云继续交给 PCL 后，可能因点云宽度为 0 触发除零异常，
表现为 lio_node 以 exit code -8 退出。

当前版本会在点云进入缓存和地图初始化前检查 cloud->empty()，空帧直接忽略，
正常点云处理流程不变。

修改文件：fastlio2/src/lio_node.cpp

三、补充 FAST-LIO2 的 Sophus 链接

在 fastlio2 的 CMake 配置中显式链接 Sophus::Sophus，解决部分环境下已经找到
Sophus、但编译时仍提示 sophus/so3.hpp 不存在或链接不完整的问题。
该修改不影响 FAST-LIO2 算法。

修改文件：fastlio2/CMakeLists.txt、hba/CMakeLists.txt

四、增加 PGO 保存与优化效果展示

累计 world_cloud 长时间显示时会不断增加 RViz 的渲染负担。当前配置默认关闭
world_cloud，并增加回环约束、优化前轨迹、优化后轨迹和回环修正统计。PGO 支持
正常退出时自动保存 map.pcd、poses.txt 和供 HBA 使用的 patches。

修改文件：pgo/rviz/pgo.rviz

五、移植 FAST_LIO_LOCALIZATION 重定位流程

重定位模块按照 HViktorTsoi/FAST_LIO_LOCALIZATION 的工作方式移植到 ROS 2，支持
RViz 2D Pose Estimate 初值、粗到细 Open3D ICP、匹配分数输出和持续 scan-to-map
校正，并复用当前 FAST-LIO2 与 MID-360 数据链路。

六、替换为官方 HBA 优化核心

HBA 模块替换为 hku-mars/HBA 的 ROS 2 移植核心，保留官方分层 LiDAR BA 与位姿图
平滑流程。程序读取 PGO 保存的 poses.txt 和 patches，输出优化前后地图及优化后
位姿，并增加结果统计、异常结果保护、红绿轨迹、修正量彩球和放大修正箭头。
官方 HBA 源码许可证保存在 hba/LICENSE_HKU_MARS_HBA。
